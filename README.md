
# NIRAMAY – Health & Beauty E-Commerce Platform

NIRAMAY is a full-stack e-commerce platform designed for purchasing health and beauty products online. It provides a seamless shopping experience with secure authentication, product management, cart functionality, order processing, and integrated online payments.

🚀 Features

Product Management: Browse and manage health and beauty products.

User Authentication & Authorization: Secure login using Spring Security and JWT with role-based access control.

Shopping Cart: Add, manage, and update products in the cart.

Order Processing: Handle customer orders and order-related operations.

Responsive UI: User-friendly frontend built with React.js and Tailwind CSS.

State Management: Redux for managing user sessions, cart data, and product listings.

Online Payments: Razorpay integration for secure payment processing.

Database Management: MySQL for data storage, relational schema design, and query operations.

RESTful APIs: Backend APIs for products, users, carts, and orders.

🏗️ Project Architecture

The application follows a full-stack architecture:

Frontend: React.js provides the interactive and responsive user interface.

Backend: Spring Boot handles business logic, authentication, product operations, and order processing.

Security Layer: Spring Security and JWT protect APIs and manage role-based access.

Database Layer: MySQL stores user, product, cart, and order information.

Payment Layer: Razorpay enables online payment integration.
💳 Payment Integration

NIRAMAY integrates Razorpay to facilitate online transactions. Configure valid Razorpay credentials and use the appropriate test environment before processing real payments.
